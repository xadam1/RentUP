Aplikace je v aktivním vývoji

RentUP se stále vyvíjí. Stávající funkce se mohou měnit, upravovat a do budoucna budou přibývat další. Nástroj vzniká postupně podle našich interních potřeb a zpětné vazby.

RentUP je desktopová aplikace vytvořená pro finanční poradce a manažery v naší síti. Jejím hlavním cílem je poskytnout přehled o spravovaném majetku klientů (AUM), zjednodušit vyhodnocování produkčních metrik a automatizovat výpočty pasivních příjmů. Slouží k tomu, abychom měli data na jednom místě a mohli vizualizovat náš budoucí růst.

Co to aktuálně umí?

AUM Dashboard

Přehledný řídící panel pro sledování celkového majetku pod správou (AUM), projekce pasivního příjmu a distribuce bodů pomocí interaktivních grafů.

Dynamické vzorce

Možnost definovat si vlastní matematické vzorce pro každý produkt (např. pro výpočet provizí nebo pasivního příjmu).

Historické trendy

Automatické ukládání historie změn portfolia. Můžete tak vizualizovat dlouhodobé trendy vývoje a sledovat jak váš klientský kmen roste.

Projekce budoucnosti

Modul pro simulaci a odhad budoucího vývoje portfolia a příjmů na základě aktuálních dat.

Proč instalovat přes Terminál?

RentUP zatím nedisponuje placeným vývojářským programem od Applu. Novější verze macOS (kvůli ochraně Gatekeeper) proto běžně blokují spuštění aplikace s varováním, že pochází od "neznámého vývojáře". Níže uvedený postup přes Terminál aplikaci automaticky stáhne a zároveň jí udělí potřebnou výjimku pro bezpečné spuštění.

1. Stiskněte Cmd (⌘) + Mezerník pro otevření vyhledávání Spotlight.

2. Napište Terminál a stiskněte Enter.

3. Zkopírujte příkaz níže, vložte ho do Terminálu (Cmd + V) a stiskněte Enter.

Terminal - bash
cd /tmp && curl -L -o RentUP_macOS.zip "https://github.com/xadam1/RentUP/releases/latest/download/RentUP_macOS.zip" && unzip -q -o RentUP_macOS.zip && (xattr -cr RentUP.app 2>/dev/null || true) && rm -rf /Applications/RentUP.app && mv RentUP.app /Applications/ && open /Applications/RentUP.app

Stáhněte si ZIP archiv, rozbalte jej kamkoliv v počítači a spusťte soubor RentUP.exe. Žádná zdlouhavá instalace není potřeba.
